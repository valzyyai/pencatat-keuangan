# Pengeluaran Bulanan — Personal Finance Tracker (100% Offline PWA & APK)

Aplikasi pencatat pengeluaran dan pemasukan bulanan yang ringan, cepat, dan **100% berjalan offline tanpa kuota internet**.

## ✨ Keunggulan Utama
- **🔒 100% Offline & Tanpa Internet:** Seluruh data keuangan tersimpan aman di memori perangkat pengguna sendiri tanpa dikirim ke server luar.
- **🇮🇩 / 🇬🇧 Dua Bahasa (Indonesia & Inggris):** Ganti bahasa antarmuka dan buku panduan secara instan lewat menu ⚙️ Pengaturan.
- **📊 Sisa Budget (%) Otomatis:** Persentase sisa budget otomatis dihitung dari total pemasukan bulanan dan berubah warna sesuai sisa dana.
- **🔢 Format Angka Titik Otomatis (`15.000` / `1.000.000`):** Input nominal maupun tampilan saldo otomatis menambahkan pemisah ribuan saat diketik.
- **📅 Tanggal Otomatis & Pemasukan Tanggal 1:** Pencatatan harian otomatis mengikuti tanggal hari ini, dilengkapi menu **Pemasukan Bulan Ini (Tanggal 1)** di dalam ⚙️ Pengaturan.
- **📖 Buku Panduan Terintegrasi:** Muncul saat pertama kali dibuka dan bisa diakses ulang kapan saja dari menu ⚙️ Pengaturan.
- **🔄 Reset Bulanan dengan Konfirmasi 2 Pilihan:** Mencegah salah pencet dengan dialog konfirmasi (**Ya, Reset** / **Batal**).
- **↔ Mode Landscape (2 Kolom) & Fullscreen + Tema Putih/Hitam:** Nyaman dipakai di layar HP maupun layar lebar laptop/tablet.
